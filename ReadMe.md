# Asteroid Rush

A classic space asteroid shooter game where you pilot a spaceship and shoot down asteroids.

## Tech Stack

- [Rust](https://doc.rust-lang.org/book/) — systems programming language
- [Macroquad](https://macroquad.rs/) — simple and easy to use game library

## Development

- Install Rust on your OS  **(recommended)**
    - [instructions to install rust here](https://www.rust-lang.org/tools/install), 
    - Recommended VS Code extension: `rust-lang.rust-analyzer`
    - then run `cargo run`
- Dev Container (Rust installed in a container rather than the host)
    - works fine, but since this is a UI app, you'll need extra UI-related setup on the host OS (e.g. X11 on Windows, etc.)
