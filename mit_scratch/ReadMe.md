# Space Shooter Classic

An old version of this game, originally built with [MIT Scratch](https://scratch.mit.edu/) during my first year at engineering college as a small side project.

A simple space shooter developed using Scratch.

**Play it online:** https://scratch.mit.edu/projects/559703047

## Running it yourself

1. Go to https://scratch.mit.edu/ and open the Scratch editor.
2. From the **File** menu, choose **Load from your computer**.
3. Select [`space shooter classic pic project.sb3`](<space shooter classic pic project.sb3>) from this folder.
4. Click the green flag to start playing.
